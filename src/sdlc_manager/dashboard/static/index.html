Connect your local helper

The dashboard runs in the cloud, but your code lives on your machine. A small helper bridges the two — one-time setup, then it's automatic.

One-time setup (in your repository folder):

powershell -c "irm https://sdlc-manager-36231825761.us-central1.run.app/setup.ps1 | iex"

One command, run in your repository folder — sets everything up and prints the pairing token. Prerequisites: uv (pip install uv) and the Google Cloud CLI. Already installed? Just run sdlc-helper in your repo.

The helper prints a pairing token — paste it below. It listens only on your own machine (127.0.0.1) and starts automatically with Windows from then on.
